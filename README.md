---# BayOS™
*A Sovereign, Human-Owned Cognitive Operating System*

BayOS coordinates specialized AI agents across plain Markdown files stored in user-owned local storage. It delivers maximum cognitive leverage with minimum friction, keeping the human firmly in executive control.

---

## The 8 Constitutional Principles

1. **Human Executive Supremacy:** The human operator retains 100% final decision authority. Agents act as bounded advisors and draft generators.
2. **Stage 1 Default (Earned Trust):** Every agent defaults to Read/Draft/Suggest mode. Elevation to automated execution requires earned reliability.
3. **Markdown-Native Sovereignty:** Conversation threads are ephemeral. Plain Markdown (`.md`) files on local storage represent canonical truth.
4. **The Pointer Principle:** BayOS stores understanding, relationships, and decisions—not raw external database logs.
5. **Unidirectional Privacy (W-Axis):** Sensitive financial, health, and personal identity data remain strictly sandboxed.
6. **Bounded Specialization:** Agents maintain narrow, dedicated mission scopes rather than acting as monolithic general bots.
7. **Fail-Closed Governance:** If schemas, permissions, or instructions are missing or ambiguous, execution halts immediately for human review.
8. **Read-Only Diagnostics:** Analytical and structural agents operate read-only and never mutate files directly.
